Why don't we use the border attribute?

HTML border attribute is not used because it is deprecated in modern HTML, and visual styling should be handled with CSS for better flexibility.

What is the easiest way to color every other row a different color?

The easiest way is to use the CSS :nth-child(even) or :nth-child(odd) pseudo-class on your table rows (tr).

What does the value in the parentheses of your structural pseudo-class mean? Give one other value you could use and which rows it would select.

The value inside the parentheses defines a formula or keyword for a repeating selection pattern, and using 3n instead would select every third row.
